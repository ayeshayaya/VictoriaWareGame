# My WarioWare-Style Mini-Game Collection

## About the Project

This project is a collection of short, interactive mini-games made in Godot for Hack Club's Stardance challenge. The goal is to complete the mini-games before time runs out.

## Built With

* Godot Engine
* GDScript

## How to Play

1. Open the game.
2. Follow the instructions presented in each mini-game.
3. Click the buttons or interact with the objects as required.
4. Complete the objective before the timer runs out.
5. Try to finish the mini-games without losing all your lives!

## Features

* Multiple mini-game scenes
* Timer-based challenges
* Interactive buttons and collectible objects
* A life system
* A completion screen

## Development

I built this project while learning Godot, working with scenes and nodes, connecting signals, writing GDScript, and implementing game mechanics.
